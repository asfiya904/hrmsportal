# 🚀 HRMS Portal

A modern Human Resource Management System (HRMS) designed to simplify employee and recruitment management processes. The platform helps streamline hiring workflows, manage employee information, and improve organizational efficiency through an easy-to-use interface.

---

## 📌 Project Overview

HRMS Portal is a full-stack web application developed to handle HR-related activities in a centralized system. It provides functionality for managing employees, recruitment processes, authentication, and data organization.

---

## ✨ Features

✅ User Authentication and Authorization
✅ Employee Management
✅ Recruitment / Hiring Management
✅ Dashboard with organized data view
✅ Add, Edit, Update and Delete records
✅ Responsive UI design
✅ Frontend and Backend integration
✅ Secure API communication

## ⚙️ Installation Steps

### Clone Repository

git clone <repository-url>

### Move to project directory

cd HRMS-Portal

### Frontend Setup

cd hireconnect_frontend

npm install

npm start

### Backend Setup

cd hireconnect_backend

Run Spring Boot application
